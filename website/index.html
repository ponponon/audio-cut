简单、专注、在你手里

每一步都清楚。

01

文件留在本机

通过系统文件选择器打开音频。解码、试听、剪切和导出都在设备上完成。

02

选区一目了然

拖动波形两端设置范围，或输入起止时间，再试听选中的片段。

03

格式由你选择

导出 MP3、M4A、WAV、FLAC、OGG 或 Opus，并可自定义文件名。

从官网安装

  1. 下载 APK 并在文件管理器中打开。
  2. 如系统询问，允许当前浏览器或文件管理器安装应用；这是 Android 对官网应用的正常提示。
  3. 安装完成后，可关闭刚才授予的安装权限。

只从本官网获取安装包。不会要求关闭系统安全检测、开启 USB 调试或安装额外配置文件。若系统提示风险，请先停止安装并通过 GitHub 项目页联系维护者。

如果手机已安装之前的测试版，因正式签名密钥不同，需要先卸载测试版再安装；之后的官网版本可直接覆盖更新。卸载会清除应用偏好，手机原有音频文件不受影响。
